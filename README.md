# DiscForge Studio

DiscForge Studio ist eine deutschsprachige Open-Source-Anwendung für Windows zum Erstellen, Prüfen und Verarbeiten optischer Datenträger und ISO-Abbilder.

## Funktionen

- Datei- und Ordnerzusammenstellung
- Brennen und Verify+
- Disc zu Image
- ISO-Werkstatt
- Multisession-Unterstützung
- Sitzungsverlauf und Berichte
- sicheres Update-Center mit Simulation, externem Updater und Rollback

## Installation

Die aktuelle MSI-Datei im Bereich **Releases** herunterladen, mit `SHA256SUMS.txt` prüfen und per Doppelklick starten.

## Dokumentation

Die Bedienungsanleitung und das Abnahmeprotokoll werden dem jeweiligen Release beigefügt.
