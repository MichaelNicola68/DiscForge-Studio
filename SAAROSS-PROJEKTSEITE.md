# DiscForge Studio 1.5

Deutschsprachige Open-Source-Anwendung für Windows zum Erstellen, Prüfen und Verarbeiten optischer Datenträger und ISO-Abbilder.

Die offiziellen Installationsdateien, Prüfsummen und der Quellcode werden ausschließlich über GitHub bereitgestellt. Die SaarOSS-Projektseite verweist auf das jeweils aktuelle GitHub Release.
